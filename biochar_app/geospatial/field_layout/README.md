# Fruita Biochar Field Layout

This directory contains the permanent geospatial reference layers for the
CSU Fruita Biochar Irrigation Experiment.

Unlike temporary GIS products (DEM clips, hillshades, orthophotos, etc.),
these files define the physical layout of the experimental field and serve
as the spatial foundation for future analyses.

---

## Source Data

### field_photo_locations.geojson

Contains GPS locations extracted from geotagged field photographs.

Important features are identified using the `feature_id` attribute.

Current named control points include:

| feature_id | Description |
|------------|-------------|
| field_nw | Northwest corner of experimental field |
| field_ne | Northeast corner |
| field_se | Southeast corner |
| field_sw | Southwest corner |
| S1T ... S4B | Logger locations |

Additional control points may be added over time.

---

## Generated Products

### Fruita_Biochar_Field_Layout.gpkg

Automatically generated by:

```
biochar_app/geospatial/build_fruita_field_layout.py
```

The GeoPackage currently contains:

| Layer | Geometry | Purpose |
|------|----------|---------|
| field_boundary | Polygon | Permanent experiment boundary |
| field_edges | LineString | North, east, south and west field edges |
| control_points | Point | Named GPS control points |
| strip_polygons | Polygon | Equal-quarter reference strips |
| strip_centerlines | LineString | Equal-quarter reference centerlines |
| logger_influence_zones | Polygon | Nearest-logger cells clipped to the field |

### logger_influence_zone_areas.csv

Audit table for the 12 logger influence zones. The cells are projected
Voronoi polygons built from the measured logger coordinates and clipped to the
photographed four-corner field boundary. Their areas exactly partition the
field and are the active areas used by irrigation storage calculations.
- irrigation head line
- furrow direction
- DEM clipping polygons
- drainage flow paths

---

## Coordinate Systems

Input GPS coordinates:

- EPSG:4326 (WGS84)

Processing:

- EPSG:3742 (NAD83(HARN) / UTM Zone 12N)

All lengths and areas are computed in projected coordinates.

## Workflow

```
field_photo_locations.geojson
            │
            ▼
build_fruita_field_layout.py
            │
            ▼
Fruita_Biochar_Field_Layout.gpkg
            │
            ▼
QGIS
DEM processing
Drone mapping
Water-balance analyses
Website maps
```

The GeoPackage should never be edited manually.

Instead:

1. Edit or add control points.
2. Re-run `build_fruita_field_layout.py`.
3. Replace the generated GeoPackage.

This ensures that all derived spatial products remain reproducible.

## Regenerating the GeoPackage

The GeoPackage is a generated product and is not maintained manually.

To regenerate it:

```bash
python biochar_app/geospatial/build_fruita_field_layout.py
```

This recreates:

```
Fruita_Biochar_Field_Layout.gpkg
logger_influence_zone_areas.csv
fruita_field_layout.png
../../static/images/experiment_design/field_layout.webp
```

The PNG is the high-resolution audit image. The WebP is the website asset and
is generated from the same figure during the same run. QGIS is not required to
regenerate the website diagram.
