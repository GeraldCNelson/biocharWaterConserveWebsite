# Python Requirements

## base.txt
Packages required to run the Biochar Water Conservation website.

## geospatial.txt
Additional packages for GIS, LiDAR, DEM processing, and terrain analysis.

## dev.txt
Development tools including pytest, Ruff, MyPy, Pyright, and Playwright.

Install examples:

pip install -r requirements/base.txt
pip install -r requirements/geospatial.txt
pip install -r requirements/dev.txt
